# Опционально: PyTorch с поддержкой NVIDIA CUDA (для GPU-инференса/обучения).
#
# torch/torchvision/torchaudio из base.txt ставятся как CPU-only wheel:
#   pip install -r base.txt --index-url https://download.pytorch.org/whl/cpu --extra-index-url https://pypi.org/simple
#
# Если на машине есть NVIDIA GPU и нужен CUDA — после base.txt переустановите
# torch с нужной версией CUDA одной командой (подставьте свою версию):
#
#   pip install torch==2.4.1 torchvision==0.19.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121
#
# Варианты index-url: cu118, cu121, cu124, cu128 — смотрите поддерживаемые
# версии для вашей версии torch на https://pytorch.org/get-started/locally/
#
# Проверка после установки:
#   python -c "import torch; print(torch.cuda.is_available())"
#
# nvidia-cu12-* ниже — runtime-библиотеки CUDA, которые сам torch+cuXXX
# подтягивает автоматически как зависимости. Явные пины здесь нужны только
# чтобы зафиксировать версии в случае, если pip их не разрешит сам.
